# Eunjeong Lee GitHub Pages Site

This repository is prepared for GitHub Pages with the Cayman theme.

## How to publish

1. Create a GitHub repository named `YOUR-USERNAME.github.io`.
2. Upload all files in this folder.
3. In **Settings → Pages**, choose **Deploy from a branch**.
4. Select the `main` branch and the root folder.
5. Wait a minute or two for the site to build.

## How to edit later

- Simple edits: change the `.md` files directly on GitHub.
- Frequent edits: use `github.dev` or VS Code.
- Styling: edit `assets/css/style.scss`.
- Navigation: edit `_includes/nav.html`.
- Footer and page layout: edit `_layouts/default.html`.
